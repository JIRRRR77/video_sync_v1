# 生日网页成品下载

本目录提供可直接部署的精修版，来源于网页修复提交 `106ebde`。

- [下载网页 ZIP](birthday-gift-refined.zip?raw=true)：包含 `index.html` 和使用说明。
- [单文件网页](index.html?raw=true)：已内嵌 CSS、JavaScript 和默认祝福文案。

下载 ZIP 并解压，将直接包含 `index.html` 的文件夹上传至 Netlify Drop，即可获得公开网址。

本版本已修复整张礼品券下载（含右侧票根、条码及缺口），以及再次点击「已收好这份心意」没有反馈的问题，28 项浏览器检查通过。原照片及歌曲音频尚未附带，可通过部署后网站的 `?edit` 制作入口导入，并导出新网页后重新部署。
